# Photo Manager

Application Vue 3 + Vite + TypeScript pour analyser et organiser des photos/vidéos locales.

## Démarrage

```bash
npm install
npm run dev
```

Ouvrir dans Chrome ou Edge (API File System Access requise).

## Fonctionnalités

- Analyse récursive d’un répertoire
- Rapport + organigramme avec compteurs par dossier
- Détection de doublons d’images (average hash)
- Organisation en dossiers `année/mois`
